# User documentation

These documents explain how to install and operate ATLANTIS.

ATLANTIS is intended to be used with NetFlow data. The pipeline creates a SQLite database from that NetFlow data that the dashboard reads.

## First use

1. [Install the tools and check the checkout](setup-web.md).
2. [Define a dataset](datasets.md).
3. [Build and verify the database](setup-pipeline.md).
4. Start the dashboard with the procedure in [Web setup](setup-web.md#run-the-dashboard).

## Other tasks

- [Verify, publish, and deploy](operations.md)

The [code documentation](../code/README.md) gives architecture and development information.
