# User documentation

ATLANTIS reads nfcapd captures, builds a SQLite database with the pipeline, and shows it in the dashboard.

## First use

1. Install the [required tools](requirements.md).
2. [Install the project](setup-web.md#install).
3. [Configure a dataset](datasets.md) that points at your captures.
4. [Build and verify a database](setup-pipeline.md).
5. [Run the dashboard](setup-web.md#run-the-dashboard).

If a step fails, read [Troubleshooting](troubleshooting.md).
